London Air Quality Data API

Open, read-only access to gridded air quality data using standard OGC services. Every operation is an HTTP GET, so you can call it from curl, Python, R, QGIS or any GIS tool.

Base URL
https://api.airtext.info/geoserver/london
Which service? Use WMS to get a ready-made map image. Use WCS to download the raw pixel values as a GeoTIFF for analysis. Layer / coverage: london:NO2 (WMS) and NO2 (WCS). Time values are ISO 8601 UTC, e.g. 2026-10-09T00:00:00.000Z.
