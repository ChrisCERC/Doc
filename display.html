Local Installation & Setup

Follow these steps to pull down the repository and run the display locally for testing:

git clone https://github.com/your-org/airtext-jcd-display.git
cd airtext-jcd-display
# Install dependencies
npm install

# Start local dev server
npm run dev

The local server will spin up on http://localhost:3000. You can test different variant query flags locally by opening http://localhost:3000/?variant=moderate.
