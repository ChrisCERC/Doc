WCS: raw data

GET /wcs Downloads the coverage rendered as a visual PNG image or GeoTIFF grid.
Downloads raw grid values or visual representations for an area and time.
Example Visual Render Preview:

Parameters

Name Description
service *
string 		Must be WCS. (Default: WCS)
version *
string 		WCS version standard. (Default: 2.0.0)
request *
string 		Must be GetCoverage. (Default: GetCoverage)
coverageId *
string 		Pollutant to download. One of: NO2, PM10, PM25, O3, Total. (Default: NO2)
format *
string 		Output format. Use image/tiff for GeoTIFF or image/png for visual render. (Default: image/png)
subset *
string 		Output geographical area (longitude). Example: Long(-0.12,-0.11)
subset *
string 		Output geographical area (latitude). Example: Lat(51.51,51.52)
subset *
string 		Date and time filter. Example: time("2026-10-09T00:00:00.000Z")

CURL Command

curl -G "https://api.airtext.info/geoserver/london/wcs" \
    --data-urlencode "service=WCS" \
    --data-urlencode "version=2.0.0" \
    --data-urlencode "request=GetCoverage" \
    --data-urlencode "coverageId=NO2" \
    --data-urlencode "format=image/png" \
    --data-urlencode "subset=Long(-0.12,-0.11)" \
    --data-urlencode "subset=Lat(51.51,51.52)" \
    --data-urlencode 'subset=time("2026-10-09T00:00:00.000Z")' \
    -o no2.png

Responses

200 OK
image/png or image/tiff payload returned successfully.
400 Bad Request
Invalid subset boundary or time slice not available.
