WMS API definition

[ Base URL: api.airtext.info/ ]
GET /geoserver/london/wms Renders airTEXT maps.

Provides URLs that can be used to view map layers.

Note for GIS Software & Libraries:
When adding this WMS service to desktop GIS applications (such as QGIS or ArcGIS) or web mapping libraries (like OpenLayers or Leaflet), bounding box (bbox), image dimensions (width, height), and spatial reference (srs/crs) parameters are typically calculated and managed automatically by the client software as you pan and zoom.

Parameters

Name Description
service *
string 		Must be WMS.
version *
string 		WMS version standard
Available values: 1.3.0, 1.1.0
request *
string 		Must be GetMap.
layers *
string 		Pollutant layer
Available values: NO2, PM10, PM25, O3, Total
time *
ISO 8601 timestamp 		Date (YYYY-MM-DDT00:00:00.000Z)
Example: 2026-12-25T00:00:00.000Z
format *
string 		Image format.
Available values: image/png, image/jpeg
srs *
string 		Coordinate system in WGS84, British National Grid or Google.
Available values: EPSG:4326, EPSG:27700, EPSG:900913
bbox *
string 		Bounding box in map coordinates.
Example: 51.069,-0.853,51.721,0.337
width *
integer 		Width of the output image (pixels)
height *
integer 		Height of the output image (pixels)

CURL Command

curl -G "https://api.airtext.info/geoserver/london/wms" \
    --data-urlencode "service=WMS" \
    --data-urlencode "version=1.3.0" \
    --data-urlencode "request=GetMap" \
    --data-urlencode "layers=NO2" \
    --data-urlencode "time=2026-12-25T00:00:00.000Z" \
    --data-urlencode "format=image/png" \
    --data-urlencode "srs=EPSG:4326" \
    --data-urlencode "bbox=51.069,-0.853,51.721,0.337" \
    --data-urlencode 'width=600' \
    --data-urlencode 'height=400' \
    -o no2.png

Responses

200 OK
image/png or image/jpeg payload returned successfully.
400 Bad Request
